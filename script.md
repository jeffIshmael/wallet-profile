# Chainalyse Demo Video Script

Target length: 2:40-3:00  
Format: judge demo / product walkthrough  
Goal: show the problem, the core product flow, the official financial passport, onchain verification, and the OnFRA agent chat.

## Recording Structure

Record this as 5 short clips:

1. Landing page and problem statement
2. Wallet connection and analysis start
3. Dashboard, scores, and transactions
4. Statement/report downloads
5. Verification and OnFRA agent chat

This keeps the recording clean and avoids needing one perfect take.

## Full Script

### 0:00-0:25 — Problem + Landing Page

**Show:** Chainalyse landing page. Scroll slightly to show Celo support and OnFRA if useful.

**Narration:**

This is Chainalyse, powered by OnFRA: an onchain financial reputation agent for the Celo ecosystem.

The problem we are solving is simple: your wallet knows your income, but your lender does not.

Millions of freelancers, creators, remote workers, and DAO contributors receive payments in crypto, but when they apply for loans, they are still asked for bank statements, payslips, or employment records that do not reflect their real financial history.

Chainalyse turns wallet activity into lender-ready financial intelligence.

### 0:25-0:50 — Connect Wallet + Start Analysis

**Show:** Connect wallet, authenticate, and start wallet analysis.

**Narration:**

The user starts by connecting their wallet.

Once connected, Chainalyse lets OnFRA analyze their onchain activity on Celo, including income patterns, savings behavior, wallet maturity, transaction history, and financial consistency.

Instead of manually filling out financial forms, the wallet becomes the source of truth.

### 0:50-1:25 — Dashboard + Scores

**Show:** Dashboard summary with financial health, reputation, income stability, and loan capacity.

**Narration:**

After analysis, the user gets a financial dashboard.

Here we summarize the wallet into practical financial scores: financial health, reputation, income stability, and estimated loan capacity.

The goal is not just to show raw blockchain data. The goal is to translate wallet behavior into something a lender, underwriter, or financial platform can understand quickly.

### 1:25-1:50 — Transactions Section

**Show:** Scroll to the transactions section.

**Narration:**

The user can still inspect the underlying transactions.

This matters because the analysis is grounded in transparent onchain data. The dashboard gives the summary, but the transaction section gives the evidence behind it.

### 1:50-2:15 — Download Statement + Official Report

**Show:** Download the transaction statement, then download or open the official financial passport/report.

**Narration:**

From here, the user can download a transaction statement for their wallet activity.

More importantly, they can generate an official Chainalyse financial passport: a lender-ready report that includes scores, income insights, borrowing recommendations, and a verification code.

This is what the user can share when they need to prove financial reputation from crypto income.

### 2:15-2:40 — Verify Report Onchain

**Show:** Verification page. Paste the verification code or show where the code is on the report. Show the verified result if available.

**Narration:**

The report is not just a static PDF.

It can be registered onchain and verified later using the report code. A lender can paste the code, confirm the wallet, scores, report hash, and registry data, and know the report was issued by Chainalyse.

That makes the financial passport portable and verifiable.

### 2:40-3:00 — OnFRA Agent Chat + Close

**Show:** Open the OnFRA agent chat. Ask a simple question or show the chat interface.

Suggested prompt:

```text
What does this wallet's activity say about loan readiness?
```

**Narration:**

Finally, users can also talk directly to OnFRA.

They can ask questions about the wallet, the report, transactions, risk, or loan readiness in natural language.

So the complete flow is: connect a wallet, analyze financial behavior, generate a financial passport, verify it onchain, and ask the OnFRA agent for deeper insight.

Chainalyse turns crypto income into financial reputation: readable for users, useful for lenders, and verifiable onchain.

## Must-Show Judge Moments

- Problem: crypto earners cannot easily prove income to lenders.
- Wallet connection and analysis.
- Dashboard with financial health, reputation, income stability, and loan capacity.
- Transaction evidence behind the scores.
- Downloadable transaction statement.
- Official Chainalyse financial passport/report.
- Report verification code.
- Onchain verification result.
- OnFRA agent chat.
- Celo / ERC-8004 agent identity if visible.

## Avoid Showing

- Long loading states.
- Debugging or dev server output.
- Environment variables or private keys.
- Wallet setup friction.
- Every landing page section.
- Every transaction row.

## Recording Notes

- Use Screen Studio if possible for the polished floating-window style.
- Record the app in a browser window, not the full desktop.
- Keep the webcam bubble small and in the bottom-right corner.
- Use only 2 or 3 zooms: dashboard scores, report verification, and agent chat.
- If analysis takes time, trim the wait or record the completed state.
- Keep narration focused on why each feature matters for financial reputation and lender trust.
