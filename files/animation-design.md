I actually wouldn't animate the wallet address itself.

The animation should tell the story of:

> **Raw wallet activity → Financial intelligence**

because that's your entire value proposition.

The reason the example works is because the animation visually demonstrates:

```txt
Money
↓
Protocol
↓
Yield
```

For ChainLens, the animation should demonstrate:

```txt
Wallet
↓
Analysis
↓
Financial Reputation
```

## Wallet → Lens → Scores

Imagine a glowing wallet address entering from the left.

```txt
0x7A3...F91
```

As it moves toward the center, it passes through a large glowing lens.

Inside the lens:

```txt
Transactions
Income
Savings
Activity
Portfolio
```

swirl around.

Then on the right, cards appear:

```txt
Financial Health
92
```

```txt
Reputation
88
```

```txt
Income Stability
95
```

```txt
Loan Capacity
KES 120,000
```

The animation continuously loops.

### Visual Message

```txt
Wallet
↓
AI Analysis
↓
Insights
```

Which is exactly what ChainLens does.
