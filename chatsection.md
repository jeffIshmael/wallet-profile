# The agent chat section

- The onchain financial reputation agent platform will also have a chat section. 
- The use can ask about their wallet in this section, 
For example:-
    - “Can I safely spend 15k?”
    - “Why did my score drop?”
    - “How can I improve my wallet reputation?”
    - “What’s hurting my financial health?”
  
- Apart from that they can also ask questions about other wallets.
For example ;-
    - "What's the financial health for "0x..."?"
    - "Can I trust "0x..." wallet?"

## Note
- Asking any question on the chat concerning a wallet will charge a X402 cost of each question.
- Charges:-
    - Any request on a wallet - 0.05 USDT
    - Generating the report - 0.1 USDT
