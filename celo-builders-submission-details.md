## Submission Description Draft

```text
Chainalyse solves the proof-of-income problem for crypto-native workers. Freelancers, creators, DAO contributors, and remote workers often receive income onchain, but lenders still ask for bank statements or payslips that do not reflect their real financial history.

OnFRA analyzes Celo wallet activity and turns raw blockchain data into lender-ready financial intelligence. The platform computes financial health, wallet reputation, income stability, portfolio risk, and estimated loan capacity. Users can inspect the underlying transaction evidence, download transaction statements, generate an official financial passport, and register verified reports onchain.

Each verified report is pinned to IPFS and published through the OnchainReporter contract on Celo. A lender or third party can verify the report later using a REP verification code, confirming the wallet, scores, report hash, and registry data. OnFRA is also registered as ERC-8004 agent #9219 on Celo, making the agent discoverable and reputation-aware.

The result is a portable financial reputation layer for crypto earners: readable for users, useful for lenders, and verifiable onchain.
```
